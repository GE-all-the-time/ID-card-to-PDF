# 🆔 身份证 1:1 精准透视校正与 PDF 拼版工具

> **一个基于 Python、OpenCV 和 Tkinter 开发的高精度证件扫描校正与 A4 PDF 拼版工具。**
> 专门解决手机拍摄身份证/卡片时产生的**倾斜透视变形、背景杂乱、黑边干扰以及打印尺寸不一致**等痛点。

---

## ✨ 核心特性

* 🤖 **智能边缘自动识别**：基于 Otsu 二值化与直线拟合算法，能够自动剔除卡片圆角（R角）干扰，精准定位四角透视锚点。
* 📐 **1:1 物理尺寸精准还原**：默认内置标准身份证尺寸（85.6mm × 54.0mm），支持自定义任何卡片的高宽尺寸。
* 🧹 **智能去除/白化边缘黑边**：采用泛洪填充（FloodFill）与边缘阈值算法，自动清洗拍摄背景产生的黑边与阴影。
* ⚡ **极速单点连续流 UI 逻辑**：点击“确认并保存当前页”后**自动保存并无缝跳转至下一张**，大幅减少鼠标跨区域往复点击。
* 📑 **可视化排版与顺序管理**：动态展示 A4 页面拼版分组（每页 A4 智能容纳 2 张卡片，分为正面/反面），支持自由上移、下移、删除与实时预览。
* 🚀 **高质量 1:1 PDF 导出**：使用 ReportLab 按照绝对毫米单位生成矢量级 PDF，确保打印机在 100% 比例下打印出与原卡完全一致的物理尺寸。

## 🛠️ 技术实现原理

本项目的核心运作流程分为**图像处理**、**GUI 画布交互**与**PDF 物理排版**三大模块：

```
[原始图片/多选] ➔ [OpenCV 智能找角 & 圆角避让] ➔ [透视变换 & 白化黑边] ➔ [单点连续保存] ➔ [ReportLab 1:1 毫米换算] ➔ [导出 A4 PDF]

```

### 1. 图像处理算法 (`OpenCV` & `NumPy`)

* **圆角避让与边缘拟合**：灰度化与高斯降噪后，通过形态学闭运算获取外接矩形。针对卡片四条边，算法仅截取中间 20%~80% 区域的边缘点阵，使用 `cv2.fitLine`（最小二乘法）拟合出 4 条直线，最后通过求直线延长线交点确定准确的物理四角，彻底解决卡片圆角导致拟合偏深的问题。
* **透视校正**：通过 `cv2.getPerspectiveTransform` 与 `cv2.warpPerspective` 进行 300 DPI 级别的双三次插值（Cubic Interpolation）透视变换重采样。
* **背景黑边清洗**：利用阈值分割生成边缘遮罩，结合 `cv2.floodFill` 从图像最外侧边缘注入白化种子，将暗色拍摄背景自动清理为纯白。

### 2. GUI 交互逻辑 (`Tkinter` + `Pillow`)

* 基于 `tkinter.Canvas` 构建交互式视口，自动根据屏幕分辨率计算渲染缩放比 (`display_scale`)。
* 动态绑定鼠标拖拽事件，实时联动矢量绘制控制点与辅助线。
* 提供多窗口逻辑，通过子窗口（`Toplevel`）实现卡片的组装列表管理与分组可视化。

### 3. PDF 生成引擎 (`ReportLab`)

* 采用 `reportlab.lib.units.mm` 将毫米（mm）转换为 PDF 点数（Pt）。
* 精确计算 A4 页面（210mm × 297mm）的中央轴线，自动将卡片对齐放置于页面上半部与下半部，导出时清空临时缓存文件。

## 📦 打包为独立运行程序 (.exe)

本仓库提供了一个纯净兼容的 PowerShell 打包脚本 `package.ps1`。在没有安装 Python 环境的 Windows 电脑上，你可以直接运行打包生成的单文件可执行程序。

### 打包步骤：

1. 打开 PowerShell 窗口，进入项目根目录。
2. （可选）如果系统提示禁止脚本运行，先执行一次权限解除命令：
```powershell
Set-ExecutionPolicy -Scope Process Bypass

```


3. 运行自动化打包脚本：
```powershell
.\package.ps1

```



### 打包脚本做了什么？

* 自动检查并安装/更新打包所需的依赖包 (`pyinstaller`, `opencv-python`, `pillow` 等)。
* 自动清理历史构建产生的 `build/`、`dist/` 临时文件夹与 `.spec` 文件。
* 使用 `python -m PyInstaller` 指令静默打包（避开系统环境变量 PATH 未配置的常见报错）。
* 打包参数说明：
* `--noconsole`：隐藏后台黑框命令行窗口。
* `--onefile`：将所有依赖压缩打包为一个单独的 `.exe` 可执行文件。


* 打包完成后，你可以在生成的 **`dist/core.exe`** 找到可执行文件并自由分发。

## 🖨️ 打印特别提示

使用导出的 PDF 文件进行打印时，为了确保打印出的身份证尺寸与真实卡片 **1:1 完全一致**，请务必在打印设置窗口中做如下配置：

* **页面缩放 (Page Scaling)**：选择 **`实际大小 (Actual Size)`** 或 **`100% 缩放`**。
* **切勿** 勾选 *“适合可打印区域 (Fit to Printable Area)”* 或 *“按纸张大小缩放”*，否则会导致打印出来的证件偏小。
